# mIV Sound icons

Extracted from mImageViewer `assets/effetune.ico`, generated by its
`scripts/generate-effetune-icon.py` (the mIV icon with a musical note).
Source SHA-256: `c32085d533dd55e2f1c2e2539d8a64304ee3a9e4bb0947406f1a959870c5d164`.

PNG files use the smallest ICO frame at least as large as the requested size,
or the largest frame (256 pixels), converted to RGBA and resized with Pillow
LANCZOS where needed. `favicon.ico` is an exact copy of the source.
The UI generator replaces all upstream app icon variants with these files.
Unused desktop marketing images are omitted; `bus_function.png` is a functional
audio routing diagram and is retained.
